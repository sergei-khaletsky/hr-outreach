## Дефолты планирования

| Параметр | Значение |
|----------|----------|
| Рабочие часы | 10:00–19:00 |
| Лимит Task-часов в день | 4 ч |
| Максимальная длина блока | 2 ч |
| Перерыв между блоками одной задачи | ≥ 15 мин |
| Длительность Task, если не указана | 1 ч |
| Уведомление | popup за 60 мин, у каждого события |
| Reminder | `availability: AVAILABILITY_FREE` |
| Язык названий (summary) | английский, всегда |
| Видимость | `visibility: private`, у каждого события |
| Цвет | Tomato (`colorId: 11`), у каждого события |
