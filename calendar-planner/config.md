# Конфиг calendar-planner

Правишь значения здесь — скилл читает файл на шаге INIT и меняет поведение. Никакого кода.

## Время

| Параметр | Значение |
|----------|----------|
| Часовой пояс | auto (из primary-календаря через `list_calendars`) |
| Рабочие часы | 10:00–19:00 |
| Рабочие дни | пн–пт |
| Лимит задач в день | 4 часа |
| Зазор между блоками | 15 минут |
| Буфер до дедлайна | минимум полдня |

## Длительности по умолчанию

| Тип | Длительность | Уведомление |
|-----|--------------|-------------|
| Task | 60 минут | popup за 1 час (60 минут) |
| Reminder | 15 минут | popup за 1 час (60 минут) |
| Максимальный блок Task | 2 часа (длиннее — резать на части) |

> Правило уведомлений: **всем** создаваемым событиям (Task и Reminder) ставить popup за 60 минут до начала. Это дефолт, менять только по явной просьбе.
