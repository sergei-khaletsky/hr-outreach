# Calendar Planner

Личный IT-менеджер в Claude Code / Cowork: кидаешь задачи свободным текстом — Claude разбирает их, находит свободные слоты в Google Calendar и создаёт события с названием, описанием, началом и концом. Два типа записей: **🔨 Task** (блок работы) и **🔔 Reminder** (напоминание).

## Установка (один раз)

1. Подключить официальный коннектор Google Calendar: **claude.ai → Settings → Connectors → Browse connectors → Google Calendar → Connect** (OAuth через нужный Google-аккаунт).
2. В чате/сессии, где будешь планировать, включить коннектор в настройках чата (иконка коннекторов → Google Calendar → on).
3. Убедиться, что этот репозиторий доступен сессии (скилл читает `calendar-planner/SKILL.md` и `calendar-planner/config.md`).

## Использование

Пишешь как человеку:

```
/plan доделать TV-часть HealthMe к четвергу, часа 3.
И напомни в среду про дедлайн гипотезы по AI-PM.
```

```
запланируй на эту неделю: разобрать отклики hh (~1ч),
подготовить питч для Scalora (2ч, дедлайн пятница),
напомнить в пт утром отправить отчёт
```

Claude ответит таблицей: что создано, когда, со ссылками на события — и честно скажет, если что-то не влезло до дедлайна.

## Что получается в календаре

- `🔨 Подготовить питч для Scalora (1/1)` — вт 10:00–12:00, в описании проект, дедлайн и критерии готовности
- `🔔 Дедлайн завтра: гипотеза AI-PM` — 15 минут с popup-уведомлением

Правила по умолчанию (рабочие часы 10–19, лимит 4 ч задач в день, блоки до 2 ч) лежат в [config.md](config.md) — правь под себя.

## Документация

- [SKILL.md](SKILL.md) — полная спецификация скилла: парсинг, подбор слотов, шаблоны событий, правила стресс-планирования
- [config.md](config.md) — настройки: часы, длительности, теги проектов
